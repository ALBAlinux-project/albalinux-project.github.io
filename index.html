Aurore Player

Norrsken Linux 向けの音声プレーヤー

mp3、flac、wav、ogg、m4a、aac を直接再生します。WMA と WMV は ffmpeg を呼び出して読み込み、一時ファイルは作りません。

依存パッケージ（Arch Linux）
sudo pacman -S gtk3 alsa-lib ffmpeg rust
ビルド
git clone https://github.com/ALBAlinux-project/Aurore-player.git
cd Aurore-player
cargo build --release --locked
./target/release/aurore-player
パッケージ化
makepkg -si
